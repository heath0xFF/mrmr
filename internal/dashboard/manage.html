                Which service should mrmr watch?
                

                  Choose exact Linux units and their service scope. User
                  services are limited to the runtime account. Scope is fixed
                  after activation. Applications can write error text at info
                  severity; choose info and higher when journald does not label
                  their errors separately.

                      effects. Inference may incur cost.

                  Discord delivery.
                

              

            

            

            
          

          

            

              

                
Advanced configuration

                

                  Forms edit shared defaults and sources. Per-monitor contracts
                  are preserved in YAML under monitors. Validation
                  checks the structure, not model connectivity. Nothing changes
                  until activation.
                

              

              
            

            

              

                

                  
                  
                

                
            

              Only credential references belong here—never passwords, API keys,
              or webhook URLs. Listener and database changes require a process
              restart. Management permits explicitly confirmed live
              notifications. Actions and delegation must remain in shadow.
            

            

              
              
            

            

            

              Active → editor difference
              

            

            
                

              Model, source, and policy forms
              

                These forms update the editor, not the running configuration.
                Edit interpretation contracts and advanced mappings in YAML
                below. Policy rules use first-match order. Forms replace YAML
                formatting and comments. Validate after manual YAML edits to
                refresh the lists.

Sources in this draft

            

            

              Pause preserves the source name and cursor. Resume reads available
              records after that cursor; it does not replay completed effects.
              Removed or renamed sources need an explicit collection-scope
              review.
            

                

                

            
Active connection references

            

              Credential presence only. No external connection test is made, and
              secret values never leave the runtime.
            

            

                

                

            
Revision history and recovery

            

              Restore loads an earlier revision into the editor. Review, save,
              and activate it to roll back future behavior. It does not undo
              effects already sent.
            

            

                

              

            

          

        

        

          

            

              
Runtime

              

                The web UI controls mrmr, not the operating system. If this
                process is down, use its service manager to recover it.
              

            

          

          

            

              
              
Safety gate

            

            

              Return to shadow blocks effects immediately before adapter
              dispatch, including work still interpreting under an older
              revision. It cannot recall an effect already sent. The gate
              survives restart and cannot be lifted from this UI.

How latency is measured

Client-side time, summed across attempts. Includes network and server work; excludes retry waits. Not GPU-only inference time. Percentiles use successful decisions only, with the nearest-rank method.

Timeouts are failed decisions whose recorded error names a timeout or expired deadline, not individual retry counts. Model history is not a live model-health check.
